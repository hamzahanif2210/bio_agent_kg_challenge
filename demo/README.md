# demo: interactive pictures

Self-contained HTML pages made by `python -m bioagent ... ask --html`; open them in any browser (works offline). Green edges were kept, dashed red edges were pruned; click an edge for its source, evidence, verdict and reason; drag the slider to see what a different confidence cut-off would do.

| Page | Question |
|---|---|
| `brca1.html` | What is known about BRCA1? |
| `egfr_nsclc.html` | How is EGFR connected to non-small cell lung carcinoma? |
| `egfr_nsclc_3hop.html` | The same, paths of up to 3 hops, confidence 0.8 and above |
