Bio-Agent Knowledge Graph

An AI agent that builds, prunes, explains and answers questions over a Biolink-aligned biomedical knowledge graph made from Pharos, so a researcher can see not only what is connected but why, and how far to trust it.

What it does

Ingest

A tool-calling agent over the live Pharos API, with a cache, step and token caps, and a guard that keeps held-out edges out.

Prune

Rules, CRAPome contaminants, obsolete-term remapping, PubMed co-mention tiers and an LLM judge. Every verdict has a rule, reason and confidence.

Ask

A name, a pair, or a full sentence. The LLM only picks out the names; every fact comes from the graph. Up to 5 hops, with filters on confidence and node type.

Explain

Why does A connect to B? Source, evidence, verdict, and paths through shared neighbours.

Bring your own data

Upload a CSV of your measurements. Each row gets a keep or prune verdict with a stated reason.

Maintain

Re-fetch targets and report what was added, removed or re-scored.

Standards

Biolink 4.4.6 predicates, genes split from proteins, OBO classes and IRIs on every node and edge.

Runs in agent harnesses

One Agent Skill, verified in NVIDIA NemoClaw sandboxes with OpenClaw and Hermes on Brev, and in pi.

Quick start

git clone https://github.com/hamzahanif2210/bio_agent_kg_challenge && cd bio_agent_kg_challenge
pip install -r requirements-serve.txt && export PYTHONPATH=src
python -m bioagent --graph sample/sample.whole serve            # web page at http://127.0.0.1:8000
python -m bioagent --graph sample/sample.whole ask --entities EGFR "non-small cell lung carcinoma" --hops 3 --min-conf 0.8
python -m bioagent --graph sample/sample.whole explain EGFR "non-small cell lung carcinoma"
python -m bioagent --graph sample/sample.whole ingest-csv sample/example_measurements.csv --out mine

Agents and deployment

One Agent Skill, installed by copying a folder, works in pi, OpenClaw, NemoClaw and Hermes Agent. On NVIDIA Brev, deploy/brev/nemoclaw.sh goes from a fresh instance to a sandboxed agent in one command: it installs NemoClaw, creates the sandbox, allows only PyPI through the network policy, installs the skill and asks a test question.
